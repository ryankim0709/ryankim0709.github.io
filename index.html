Software Engineering Intern

Teserac AI · May – Aug 2026 · Full-time

Digital Twin graph API

I re-architected the graph API behind a browser-based single-line-diagram editor for datacenter power topology, splitting it into independently versioned planes and writing the topology and layout-intent planes myself. Operator layout is versioned by integer revision and SHA-256 hash, so two people editing the same diagram can no longer quietly overwrite each other.

Deterministic layout and canvas performance

Large diagrams now render roughly 3× faster: a structural topology fingerprint lets live power polling update values without forcing a relayout. I wrote the layout and grouping algorithms underneath — fixed-order synthetic ELK ports so component rows come out the same way every time, and a clear-then-regroup organize service that leaves no asset unclassified.

Async delete pipeline and stuck-job reaper

New telemetry data had pushed a single facility purge past millions of database operations. I moved the cascade delete onto a polled async job that chunks the work into 2,000-operation batches, and the deletes stopped timing out. The reaper behind it uses a stale threshold above the task’s hard limit, so a purge that is still running is never dispatched twice.
